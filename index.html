Prototype Architecture & Limitations

Welcome to PettyFlow, an advanced client-side front-end web application.

  • Client-Side Storage: All settings and transaction entries are stored locally inside this browser using localStorage and attachments inside IndexedDB.
  • Single-Device Isolation: Other employees or management cannot see your entries automatically unless you export your data or connect to a centralized backend.
  • No Server-Side Authentication: Login simulations or user roles in this front-end prototype are for demonstrative interface workflows. It is not an enterprise access control system.
  • Receipt Storage Quota: Large PDF and image uploads are stored in browser memory/IndexedDB for this demo. Clearing your browser cookies or cache will purge these files. Always keep originals or export JSON backups.
  • Production Roadmap: Deploying this for full corporate use requires a secure server backend (e.g. Node.js / Python / Go), PostgreSQL/MySQL database, secure multi-tenant authentication, and S3 bucket storage for invoices.
